# td_mebli_sale

Розміри виробу як вільні значення атрибутів у стандартному конфігураторі продажів, ціна з розмірним коефіцієнтом
`(W*H)/(W0*H0)`, специфікація під замовлення (кнопка в рядку або автоматично при підтвердженні), передача BoM у
виробниче замовлення, планова собівартість і маржа рядка (`sale_margin`). Звіт: Продажі > Звітність > Собівартість замовлень.
