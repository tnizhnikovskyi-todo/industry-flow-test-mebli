# td_mebli_cutting

Завдання розкрою: деталі з специфікацій виробничих замовлень -> файл для програми розкрою -> карта розкрою ->
резерв листів за партіями -> ділові обрізки як нові партії (побічна продукція МО).

**Розрахунок карти — імітація** (`models/optimizer.py`, смуговий розкрій). Єдина точка входу результату —
`td.mebli.cutting.job._td_apply_result(payload)`: імпорт файлу реальної програми (A-11) має подати той самий `payload`.
Формат файлу «Передати на розкрій» — чернетка.
