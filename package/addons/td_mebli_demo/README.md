# td_mebli_demo

Каталог, робочі центри й склад для показу пакета «меблі». **Клієнтам не ставиться** (клієнти отримують шаблони
майстер-даних A-13). Усі бренди вигадані. Дані — у `data/*.xml` (noupdate), залишки на складі й валюта UAH — у
`post_init_hook` (`hooks.py`).

Сценарій показу в Odoo shell: `scripts/show_scenario.py` (див. `docs/industries/mebli/prototype-real/SHOW.md`).
