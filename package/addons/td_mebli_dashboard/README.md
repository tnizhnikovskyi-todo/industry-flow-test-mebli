# td_mebli_dashboard — дашборд керівника

Екран «Фабрика на одному екрані» (меню «Керівник», клієнтська дія OWL) для Odoo 19 Community: виручка й замовлення за 30 днів,
середня маржа й замовлення з маржею нижче 15 %, завантаження дільниць, час від замовлення до запуску, % відходу розкрою й
економія від ділових обрізків, план/факт собівартості виконаних МО. Картки відкривають відповідні звіти.

Чому не `spreadsheet_dashboard`: у CE 19 є `spreadsheet_dashboard` (+ `_sale`, `_account`, `_stock_account` тощо), але немає
виробничих дашбордів (маржа замовлення, дільниці, розкрій), а `board` — лише збірка збережених подань. Тому — власна клієнтська
дія без бібліотек графіків; сітка адаптивна (телефон — одна колонка). Дані рахує `td.mebli.dashboard.get_data()`, тест — `tests/`.
