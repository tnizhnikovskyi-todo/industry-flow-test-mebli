# Картка: Замірник

Повний посібник: ../zamirnyk.md

## SC-07 Замір без помилки на монтажі
1. Увійдіть як замірник (логін — рядок «Вхід» посібника); «Заміри» → «Мій календар».
2. Зустріч → «Почати замір»: замір-лист заповнюється сам (повторно — той самий).
3. «Заміри» → «Мої заміри» → замір-лист.
4. Заповніть «Ніші й розміри», «Техніка клієнта», «Комунікації й фото».
5. Після проєкту — «Звірити з проєктом».

## Якщо не виходить
- Немає розмірів ніші -> перевірки немає, внесіть розміри.
- Чужий замір не відкривається -> так і має бути.
- Немає застосунку «Заміри» -> увійшли не як замірник.
- Інакше — «Підтримка ToDo» у верхній панелі.
