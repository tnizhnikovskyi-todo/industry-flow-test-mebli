# Картка: Налаштування довідників і товарів

Повний посібник: ../setup.md

## Порядок з нуля
1. Адміністратор: «Налаштування» → «Меблі» — % бригаді, чек-лист акта, пороги, функції коробки B.
2. Адміністратор: категорії товарів — «Гарантія, міс.».
3. Адміністратор: постачальники й покупці — ЄДРПОУ, телефон, умови оплати (стандартна форма).
4. Адміністратор: атрибути — «Роль компонента» / «Розмір виробу»; значення без «Товар-компонент» (матеріалів ще немає).
5. Технолог: товари-матеріали — «Деталі виробу» → «Вид матеріалу», розміри листа, товщина, відхід; кромка — «Підходить до плити».
6. Адміністратор: значення атрибутів — «Товар-компонент», «Товщина кромки, мм».
7. Технолог: параметричний виріб — мін / номінал / макс, правила деталей, маршрут «Поповнити замовлення (ВНЗ)» («Склад»); «Аналоги»; доплати («Налаштувати»).
8. Адміністратор: послуга порізки (вид «Послуга порізки» + постачальник), послуга монтажу («Створити замовлення» = «Завдання»), ціни постачальників.
9. Технолог: робочі центри (робочий графік), специфікація й операції — база часу, хвилини, розцінка, крок якості.
10. Адміністратор: обладнання — «Робочий центр»; терміни оплати — «Етап оплати».
11. Адміністратор: працівники — PIN-код, поле «Користувач» порожнє; причини премій і штрафів.
12. Масово: «Продажі» → «Налаштування» → «Міграція» → «Порядок імпорту шаблонів» → «Імпортувати».

## Якщо не виходить
- «Не знайдено кромки … мм для …» -> кромка з «Підходить до плити» і товщиною.
- «Оберіть декор корпусу …» -> атрибут з роллю «Плита корпусу».
- «… мін <= номінал <= макс …» -> виправте межі розмірів виробу.
- «Немає послуги порізки з дистриб'ютором …» -> послуга порізки з постачальником.
- Монтаж не з'являється в календарі -> послуга монтажу має створювати завдання.
- «Невірний PIN» працівника цеху -> у картці працівника поле «Користувач» має бути порожнім.
- Інакше — «Підтримка ToDo» у верхній панелі.
