# Картка: Налаштування довідників і товарів

Повний посібник: ../setup.md

## Порядок з нуля
1. Адміністратор: «Налаштування» → «Меблі» — % бригаді, чек-лист акта, пороги, функції коробки B.
2. Адміністратор: категорії товарів — «Гарантія, міс.».
3. Адміністратор: постачальники й покупці — «Код BAS» (блок «Різне»).
4. Адміністратор: атрибути — «Роль компонента» / «Розмір виробу», «Товар-компонент», «Товщина кромки, мм».
5. Технолог: товари — «Деталі виробу» → «Вид матеріалу», розміри листа, товщина, відхід; кромка — «Підходить до плити».
6. Технолог: параметричний виріб — мін / номінал / макс, правила деталей; «Аналоги».
7. Адміністратор: послуга порізки (вид «Послуга порізки» + постачальник), послуга монтажу («Створити замовлення» = «Завдання»), ціни постачальників.
8. Технолог: робочі центри (робочий графік), специфікація й операції — база часу, хвилини, розцінка, крок якості.
9. Адміністратор: обладнання — «Робочий центр»; терміни оплати — «Етап оплати».
10. Адміністратор: працівники — PIN-код, код BAS; причини премій і штрафів; канал BAS.
11. Масово: «Продажі» → «Налаштування» → «Міграція» → «Порядок імпорту шаблонів» → «Імпортувати».

## Якщо не виходить
- «Не знайдено кромки … мм для …» -> кромка з «Підходить до плити» і товщиною.
- «Оберіть декор корпусу …» -> атрибут з роллю «Плита корпусу».
- «… мін <= номінал <= макс …» -> виправте межі розмірів виробу.
- «Немає послуги порізки з дистриб'ютором …» -> послуга порізки з постачальником.
- Монтаж не з'являється в календарі -> послуга монтажу має створювати завдання.
- Інакше — «Підтримка ToDo» у верхній панелі.
