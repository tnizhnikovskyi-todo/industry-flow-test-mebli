# Картка: Бригадир монтажу й сервісу

Повний посібник: ../bryhadyr.md

## SC-08 Монтаж, акт, рекламація
1. «Проєкт» → «Монтаж» → «Календар монтажів».
2. «Монтаж» → «Мій день»; друк «Денний план бригади»; на задачі — «Почати монтаж».
3. «Монтаж» → «Акти монтажу» → акт.
4. Заповніть вкладки, підпис покупця → «Підписати акт»; «Друк» → «Акт монтажу».
5. Фото за згодою — «У фотоархів».
6. Рекламація (група «Сервіс»): «Ремонти» → «Рекламації» → «Новий».
7. «Запланувати виїзд» або «Повторне виготовлення».
8. «Монтаж» → «Мої нарахування».

## Якщо не виходить
- Акт не підписується -> немає підпису покупця.
- «У фотоархів» не працює -> немає згоди покупця.
- Банер про доплату -> зателефонуйте клієнту до виїзду.
- Інакше — «Підтримка ToDo» у верхній панелі.
