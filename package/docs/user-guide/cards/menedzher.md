# Картка: Менеджер продажу

Повний посібник: ../menedzher.md

## SC-01 Від заявки до запланованого монтажу
1. Після входу — головний екран; відкрийте «CRM» → нагоду.
2. «Записати на замір» → «Записати» біля вільного вікна («Оновити вікна» — інші дні).
3. «Нова пропозиція» → виріб і розміри в «Рядки замовлення»; ціна — з розмірів.
4. «Термін оплати» з етапами → перевірте «Графік оплат».
5. «Друк» → «Договір»; «Надіслати» на підпис; «Підтвердити».
6. Зміна — «Створити зміну» → «Створити» → «Зафіксувати зміну».
7. Зсув дати — «Повідомити клієнта про нову дату».
8. Етап — «Продажі» → «Замовлення» → «Дошка замовлень»; монтаж — «Календар монтажів».

## Довідка й підтримка
- Значок «Довідка» (книжка) — статті до екрана; «Підтримка ToDo» — звернення.

## Якщо не виходить
- «Немає вільних вікон» -> більше днів і «Оновити вікна».
- Договір не друкується -> режим договору задає адміністратор.
- Ціна не перераховується -> у виробу немає формули ціни (технолог).
- Задачі монтажу немає -> замовлення не підтверджене.
- Інакше — «Підтримка ToDo» у верхній панелі.
