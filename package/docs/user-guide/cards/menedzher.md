# Картка: Менеджер продажу

Повний посібник: ../menedzher.md

## SC-01 Від заявки до запланованого монтажу
1. Після входу — головний екран; відкрийте «CRM» → нагоду.
2. «Записати на замір» → «Записати» біля вільного вікна («Оновити вікна» — інші дні); «Наступна зустріч» (смарт-кнопка) — календар із замірниками нагоди.
3. «Нова пропозиція» → «Додати товар»; (B) конфігуратор: опції й розміри → «Підтвердити»; ціна — з розмірів; розмір поза межами — попередження з межами (колонка «Межі розміру, мм»). Додайте рядок «Доставка й монтаж (у вартості замовлення)» (`МОНТАЖ`) і «Обіцяна дата» (дата виїзду).
4. «Термін оплати» з етапами → перевірте «Графік оплат».
5. Жовтий блок «Ціна нижча за планову собівартість» — перевірте розмір і знижку. «Друк» (шапка) → «Договір» → «Друк»; «Надіслати» на підпис; «Підтвердити».
6. Зміна — «Створити зміну» → «Створити» → «Зафіксувати зміну».
7. Зсув дати (закупівля запізнюється) — банер і дія; «Повідомити клієнта про нову дату».
8. Етап — «Продажі» → «Замовлення» → «Дошка замовлень» (етап рухають дії в документах, не перетягування); монтаж — задача-виїзд у стадії «Заплановано» з «Обіцяною датою», «Календар монтажів»: «Кінцевий термін» і «Уповноважені».

## Довідка й підтримка
- Значок «Довідка» (книжка) — статті до екрана; «Підтримка ToDo» — звернення.

## Якщо не виходить
- «Немає вільних вікон» -> більше днів і «Оновити вікна».
- Договір не друкується -> режим договору задає адміністратор.
- Ціна не перераховується -> у виробу немає формули ціни (технолог).
- Задачі монтажу немає -> немає рядка `МОНТАЖ` або замовлення не підтверджене.
- Виїзду немає в календарі -> порожній «Кінцевий термін» (стадія «Запланувати»).
- Інакше — «Підтримка ToDo» у верхній панелі.
