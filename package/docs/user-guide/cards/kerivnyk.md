# Картка: Керівник

Повний посібник: ../kerivnyk.md

## SC-06 Від дашборда до рішення
1. Після входу — головний екран; відкрийте «Керівник».
2. Натисніть картку показника — відкриються записи.
3. «Продажі» → «Замовлення» → «Дошка замовлень».
4. «Продажі» → «Звітність» → «Собівартість: план і факт».
5. «Продажі» → «Звітність» → «Час від замовлення до запуску».
6. Брифінг о 07:30 — в «Обговорення».

## Якщо не виходить
- Картки 0 -> змініть період.
- Немає «Керівник» -> група «Керівник фабрики (дашборд)» (адміністратор).
- Брифінг не прийшов -> вихідна пошта (адміністратор).
- Інакше — «Підтримка ToDo» у верхній панелі.
