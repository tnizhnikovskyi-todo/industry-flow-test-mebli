## SC-02 Від файлу програми проєктування до розкрою й порізки
1. «Виробництво» → виробниче замовлення → вкладка «Деталі».
2. Специфікація → «Імпорт деталей» → файл → «Розпізнати колонки» → «Імпортувати».
3. Список виробничих замовлень → «Дія» → «Створити завдання розкрою».
4. Завдання: «Підтвердити» → «Передати на розкрій» (або «Передати дистриб'ютору»).
5. Результат: «Імпортувати результат» → «Імпортувати»; листи — «Розкрій» → «Листи розкрою».
6. (B) «Підібрати обрізок» → «Зарезервувати під завдання».
7. «Друк» → «Етикетки деталей (QR)».

## Якщо не виходить
- Немає обов'язкових колонок -> виправте заголовки або «Шаблони імпорту».
- Невідомий матеріал -> додайте матеріал у довідник.
- Немає деталей -> спершу імпорт деталей.
- Немає дистриб'ютора -> заповніть «Дистриб'ютор» у «Параметри розкрою».
- Інакше — «Підтримка ToDo» у верхній панелі.
