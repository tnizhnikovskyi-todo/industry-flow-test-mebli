## SC-05 Курс, обмін з BAS, собівартість, нарахування
1. «Виставлення рахунків» → «Обмін з BAS» → «Канали» → «Передати в BAS».
2. «Обмін з BAS» → «Пакети»: стан, помилки; «Імпортувати» / «Повторити».
3. «Обмін з BAS» → «Журнал».
4. «Продажі» → «Звітність» → «Собівартість: план і факт».
5. «Виробництво» → «Звітність» → «Нарахування» → «Нарахувати»; «Друк» → «Відомість нарахувань»; «Передати в BAS».
6. «Відвідування» → «Управління» → «Табель для BAS (імітація)» → «Сформувати файл».
7. Перший місяць: «Продажі» → «Налаштування» → «Міграція» → «Звірка» → «Порівняти з Odoo».
8. (B) «Продажі» → «Замовлення» → «Оновити ціни за курсом».

## Якщо не виходить
- Помилка обміну -> «Журнал», виправити, «Повторити».
- Документ у BAS не змінюється -> скасування в BAS.
- Нарахування без розцінки -> розцінка операції маршруту.
- Інакше — «Підтримка ToDo» у верхній панелі.
