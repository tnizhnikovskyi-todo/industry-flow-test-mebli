## SC-05 Курс, собівартість, нарахування (обмін з BAS — відкладено рішенням власника 2026-11-16)
1. «Продажі» → «Звітність» → «Собівартість: план і факт».
2. «Виробництво» → «Звітність» → «Нарахування» → «Нарахувати» → «Підтвердити»; «Друк» → «Відомість нарахувань».
3. Перший місяць: «Продажі» → «Налаштування» → «Міграція» → «Звірка» → «Порівняти з Odoo».
4. (B) «Продажі» → «Замовлення» → «Оновити ціни за курсом».

## Якщо не виходить
- Нарахування без розцінки -> розцінка операції маршруту.
- Оплату зареєстровано, а ручна позначка ще рахується -> «Ручні позначки оплати» замовлення → «Скасовано».
- Інакше — «Підтримка ToDo» у верхній панелі.
