# Картка: Комірник-комплектувальник і закупівля

Повний посібник: ../komirnyk.md

## SC-04 Резерв, закупівля, обрізки, повний комплект
1. Виробниче замовлення: перевірте «Статус компонентів»; (B) «Взяти аналог».
2. «Склад» → «Операції» → «Затримані поставки»; нова дата — у закупівлі.
3. «Купівля» → «Товари» → «Імпорт прайсу» → «Розпізнати колонки» → «Записати ціни».
4. «Купівля» → «Звітність» → «Ціни проти історії».
5. (B) «Склад» → «Товари» → «Ділові обрізки».
6. Доставка замовлення → «Комплектувальний лист» (лист формується з специфікацій).
7. «Склад» → «Операції» → «Комплектувальні листи»: позначте «Запаковано».
8. Доставка: «Комплектувальний лист» → «Підтвердити»; бракує деталі — «Створити дозамовлення».

## Якщо не виходить
- Невідомий код у прайсі -> не записується, перевірте код товару.
- Відвантаження не підтверджується -> комплект неповний.
- Невідома етикетка -> перевірте замовлення етикетки.
- Інакше — «Підтримка ToDo» у верхній панелі.
