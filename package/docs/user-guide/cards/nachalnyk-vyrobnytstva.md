# Картка: Начальник виробництва

Повний посібник: ../nachalnyk-vyrobnytstva.md

## SC-03 Зміна з простоєм, якістю й рекламацією
1. «Продажі» → «Замовлення» → «Дошка замовлень»: червоні картки — зсув дати.
2. «Виробництво» → «Звітність» → «Завантаження дільниць».
3. Виробниче замовлення → запуск; паперовий наряд — «Друк» → «Наряд на замовлення».
4. «Виробництво» → «Планшет цеху»: «Взято», «Пауза», «Зроблено» + PIN → «Підтвердити».
5. Простій верстата: запит на обслуговування → «Дільниця стоїть» / «Дільниця знову працює».
6. (B) Перевірки якості: «Виробництво» → «Операції» → «Перевірки якості».
7. (B) «Виробництво» → «Звітність» → «Табло цеху (ТВ)».
8. Премії й штрафи: «Виробництво» → «Звітність» → «Нарахування».

## Якщо не виходить
- «Невірний PIN» -> PIN у картці працівника (адміністратор).
- Завдання вже взяв інший -> домовтеся або візьміть інше.
- «Зроблено» не проходить -> виконайте крок якості.
- Помилка часового поясу в «Завантаження дільниць» -> адміністратор (часовий пояс).
- Інакше — «Підтримка ToDo» у верхній панелі.
