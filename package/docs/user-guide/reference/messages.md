# Повідомлення системи: довідник помилок пакета

Усі повідомлення про помилки, які показують модулі `td_*` пакета (`UserError`, `ValidationError`, `AccessError` у коді, без `td_mebli_demo` і тестів), дослівно українською за `i18n/uk.po` модулів. `%s`, `%(…)s` — місце, куди система підставляє назву, число чи дату. Стандартні повідомлення Odoo тут не наводяться. Повноту перевіряє `check_messages.py` (поруч, `python3 -I package/docs/user-guide/reference/check_messages.py --addons package/addons`): кожен текст із коду має рядок тут.

Ролі: менеджер — `menedzher.md`, технолог — `tekhnolog.md`, начальник виробництва — `nachalnyk-vyrobnytstva.md`, комірник — `komirnyk.md`, фінансист — `finansyst.md`, керівник — `kerivnyk.md`, замірник — `zamirnyk.md`, бригадир і сервіс — `bryhadyr.md`, адміністратор — `admin.md`. Помилка не з цього переліку або незрозуміла — кнопка «Надіслати в підтримку ToDo» на діалозі помилки.
