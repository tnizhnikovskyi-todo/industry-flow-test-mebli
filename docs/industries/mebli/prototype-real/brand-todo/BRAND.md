# Фірмовий стиль ToDo для продаючих матеріалів

Джерело: брендований бланк ToDo (`claude-methodology-marketplace/plugins/odoo19-discovery-closeout/skills/discovery-report-builder/assets/report_template.docx`).

- Логотип: `todo-logo.png` (знак + «ToDo», на білому/світлому фоні), `todo-mark.png` (лише знак).
- Кольори: помаранчевий ToDo `#FE5000` (акцент, кнопки, виділення), темний `#101820` (текст, темні фони), білий `#FFFFFF`; допоміжні сірі з бланка — `#808080`, `#BFBFBF`.
- Шрифт: Open Sans (Regular, Italic, Bold, BoldItalic) — `fonts/` (ліцензія Apache 2.0).
- Правило: матеріали продають рішення **ToDo** для меблевої фабрики — ToDo як автор/постачальник (логотип ToDo на заставках, у куті відео, у футері one-pager). Демо-фабрика «Меблева фабрика «Демо»» — клієнт у сценарії, її логотип лишається лише всередині Odoo.
