# Зріз пакета «меблі» на базі Odoo 19 CE — A-21, спроба 2 (ЗРАЗОК)

Статус: **зразок до приймання людиною** (`ACCEPTED.md` ставить людина; AI його не створює). Редакція зрізу — `demo_edition: ce`; EE — окремою позначкою, у зразку не перевірялась (доступу немає).

## 1. Що це
Справжні модулі `package/addons/td_mebli_*` (Python + XML + дані, без Studio й полів `x_`) на чистій базі Odoo 19.0 CE — заготовка A-11. План зрізу, перевірка припущень по вихідниках CE 19 і результат перевірки №13 — `PLAN.md`.
Зразок = 1 екран (S-02 «Замовлення клієнта»: обіцяна й прогнозна дата, зсув і причина, замовні позиції — F-23, F-31, F-36, NG-01), 15 с живого запису `video/rec/D_sample.mp4`, кадр `screens/00-sample.png`.

## 2. Як відтворити
Середовище C-00 (`tools/odoo/`) у репо відсутнє; база збиралась прямими командами, рівнозначними `shoot/build_db.sh` (перестворення бази перед зйомкою, установка, оновлення з `--i18n-overwrite --load-language uk_UA`, seed з явним `env.cr.commit()`, перевірка кількості записів):
```
source /home/user/odoo19/env.sh
dropdb --if-exists demo-mebli-sample
$ODOO_PY $ODOO_BIN -c $ODOO_CONF -d demo-mebli-sample -i td_mebli_demo --load-language uk_UA --without-demo=True --stop-after-init
$ODOO_PY $ODOO_BIN -c $ODOO_CONF -d demo-mebli-sample -u td_mebli_mrp,td_mebli_sale,td_mebli_cutting,td_mebli_dashboard,td_mebli_demo --load-language uk_UA --i18n-overwrite --stop-after-init
$ODOO_PY $ODOO_BIN shell -c $ODOO_CONF -d demo-mebli-sample < package/addons/td_mebli_demo/scripts/seed_showcase.py
psql -d demo-mebli-sample -c "SELECT count(*) FROM td_mebli_order_item"     # > 0, інакше seed не закомічено
$ODOO_PY $ODOO_BIN -c $ODOO_CONF -d demo-mebli-sample --http-port 8072 --workers=0
cd docs/industries/mebli/prototype-real/shoot
BASE=http://127.0.0.1:8072 DB=demo-mebli-sample DEMO_EMAIL_DOMAIN=demo-fabryka.example ORDER_ID=123 LATIN_OK=mebli,sample ONLY=0 node scenario.mjs
BASE=http://127.0.0.1:8072 DB=demo-mebli-sample DEMO_EMAIL_DOMAIN=demo-fabryka.example ORDER_ID=123 LATIN_OK=mebli,sample node rec_clips.mjs D_sample
```
Після останнього перестворення бази для зйомки модуль `td_mebli_sale` оновлено (`-u td_mebli_sale`) лише заради ширини колонок вкладки «Замовні позиції» — дані не змінювались; перед повним обсягом база перестворюється заново.
`ORDER_ID` — замовлення з посиланням клієнта «Кухня й шафа-купе, квартира» (seed `td_mebli_demo/dates.py`). `LATIN_OK=mebli,sample` — ім'я бази `demo-mebli-sample` у прихованому меню користувача навбару (на екрані не видно; `rec_lib.latinWords` його бачить).
