Редакція зрізу — `demo_edition: ce`; EE — окремою позначкою, **не перевірено** (доступу немає).

## 1. Що це

План, перевірка припущень по вихідниках CE 19, таблиця «Модель даних» і перевірка №13 — `PLAN.md`; оцінка функцій — `complexity.md`. ## 2. Як відтворити
C-00 `tools/odoo/` у репо немає — база збирається прямими командами, рівнозначними `shoot/build_db.sh` (перестворення перед зйомкою обов'язкове):
```
source /home/user/odoo19/env.sh
dropdb --if-exists demo-mebli-full
$ODOO_PY $ODOO_BIN -c $ODOO_CONF -d demo-mebli-full -i td_mebli_demo --load-language uk_UA --without-demo=True --stop-after-init
$ODOO_PY $ODOO_BIN -c $ODOO_CONF -d demo-mebli-full -u td_mebli_mrp,td_mebli_sale,td_mebli_cutting,td_mebli_measure,td_mebli_shop,td_mebli_install,td_mebli_claim,td_mebli_cost,td_mebli_purchase,td_mebli_ua,td_mebli_dashboard,td_mebli_demo --load-language uk_UA --i18n-overwrite --stop-after-init
$ODOO_PY $ODOO_BIN shell -c $ODOO_CONF -d demo-mebli-full < package/addons/td_mebli_demo/scripts/seed_showcase.py   # явний env.cr.commit()
psql -d demo-mebli-full -c "SELECT count(*) FROM td_mebli_install_act"   # > 0
cd docs/industries/mebli/prototype-real/shoot
ln -s "$(npm root -g)" node_modules     # playwright для ES-модулів (у .gitignore; NODE_PATH імпорти ESM не бачать)
export ODOO_SERVE_CMD="$ODOO_PY $ODOO_BIN -c $ODOO_CONF -d demo-mebli-full --http-port 8072 --workers=0 --db-filter=^demo-mebli-full\$" \
       BASE=http://127.0.0.1:8072 DB=demo-mebli-full DEMO_EMAIL_DOMAIN=demo-fabryka.example ORDER_ID=123 LATIN_OK=mebli,full
./run_all.sh demo-mebli-full td_mebli_demo - --check-table td_mebli_install_act --fix-dates mrp_workcenter_productivity:date_start --zero-cols td_expected_hours --no-build
python3 -I ../../../../../industry-flow-marketplace/plugins/flow-research/skills/prototype-builder/scripts/check_ui_text.py dom --lang uk --zero-cols td_expected_hours
```
`run_all.sh`: прохід 1 (`scenario.mjs` кроки 3, 5; кліпи `D_csv`, `D_tablet`, `M_tablet`, `D_kit`, `D_cutting`, `M_act`) -> `fix_dates.sh` -> прохід 2 (решта кроків, мобільні кроки m1–m5, кліпи з `D_dashboard`/`M_dashboard` першими). Окремий кліп: `node rec_clips.mjs M_late` (база в стані після проходу 1). `ORDER_ID=123` — замовлення показу S00123 («Кухня й шафа-купе, квартира»). `LATIN_OK=mebli,full` — ім'я бази в прихованому меню користувача (на екрані не видно). Останній рядок `run_all.sh` шукає `check_ui_text.py` поруч із собою (у `shoot/` його немає) — перевірку запускати окремо, як вище.
Зйомка хвилі 3 (2026-11-12): база перестворена після перекалібрування; прохід 1 + `fix_dates` + прохід 2 — усі десктопні й мобільні кадри з однієї бази. Кліп `M_late` у першому прогоні впав (0 кадрів телефона, ffmpeg без вхідних файлів); решта кліпів проходу 2 після нього (`M_late`, `D_measure`, `M_measure`, `D_change`, `D_install`, `D_accruals`, `D_claims`) знята повторно на тій самій базі (лише читання).

Детально — колонка «Імітація в зрізі» `complexity.md`.
- **Курс НБУ (F-26):** курси EUR/USD демо записано з таблиці демо (не реальні) з позначкою «НБУ (імітація, без мережі)»; код завантаження в стандартні курси справжній, онлайн вимкнено.
- **Обмін з BAS (F-47):** статус на замовленні й кнопка «Передати в BAS (імітація)»; обміну немає.
- **Файли CAD (F-01, F-27):** справжній імпорт CSV-вивантаження з розпізнаванням колонок за заголовками; формати програм проєктування не читаються.

## 9. Обмеження (беклог A-11)
- **Імпорт CSV додає, а не замінює деталі** (`S00123/391`: 13<!--fact:facts.D_csv.part_count--> деталей після імпорту). **Рішення AI (ризик):** у майстрі A-11 — вибір «Замінити деталі / Додати до наявних», типово «Замінити» для деталей, згенерованих з опцій; «Додати» лишається для дозамовлення після розкрою (F-44). Ризик: технолог втратить ручні правки деталей — перед заміною показувати список ручних змін.
- Прогнозна дата не враховує порізку в дистриб'ютора; готовність за закупленою позицією — від старту МО (песимістично для фасадів).
- Обрізані заголовки стандартних колонок («Замовлення на вир…», «Один…») — ширини в A-11.
- Кіоск: двоє працівників на одному завданні через один планшет одночасно не працюють; таймер робочого замовлення в CE — один на користувача.
- «Застряглі» — понад 5 днів без руху (параметр у коді; в A-11 — налаштування).
- `fix_dates.sh` зсуває й рядки часу seed, створені сьогодні (тривалість не перераховується; у кадрі не видно).
- Демо-фабрика монтує близько 69 замовлень за 30 днів однією бригадою — тому частка бригади в демо нижча за типову; для пілоту — параметр.
- Складальник Юрій Савчук за жовтень — понад 40 тисяч (великі замовлення); розподіл за обсягом рівняє лише підсумок усього періоду.
