### Критерій ранжування
`бал = 0.4·відповідність_розміру + 0.3·динаміка + 0.2·повнота + 0.1·регіон` (`selection-criteria.md` §2; `flow/params.md`, «A-05 / B-01: ваги балу вибірки (q39)» — стандартні ваги скіла, **ваги не затверджено**: затверджує Керівник напряму після першого запуску).
- відповідність_розміру = 1 (усі в діапазоні 50–249 за фільтром); динаміка = (обрізане до [−0,5; +0,5] значення `rev_2025 / rev_2024 − 1`) + 0,5, без обох років — 0; повнота = 1, якщо `kved_ambig = 0` і `employees`, `region` непорожні; регіон = 0 (пріоритетного регіону немає).
- Рівні бали — за виручкою 2025 спадно («рівний бал»): 10 компаній пулу мають 0.900 (зростання ≥ +50 %), шортліст — перші 6 із них за виручкою.

### SQL-запити
Q1 (S1, розмір пулу):
```sql
SELECT COUNT(*) AS pool, SUM(c.kved_ambig = 1) AS ambig, SUM(c.employees IS NULL) AS no_employees, SUM(c.region IS NULL OR c.region = '') AS no_region FROM companies c WHERE c.status = 'зареєстровано' AND c.has_financials = 1 AND c.source IS NULL AND c.kved_2010 LIKE '31%' AND c.employees BETWEEN 50 AND 249
```
Q2 (S2 з балом у SQL, усі 76 рядків пулу оцінено до зрізу; топ-12):
```sql
SELECT t.*, ROUND(0.4*1 + 0.3*t.dyn + 0.2*t.compl + 0.1*0, 3) AS score FROM (SELECT c.code, LEFT(c.full_name,80) AS name, c.kved_2010, c.region, c.employees, c.revenue, c.revenue_year, c.kved_ambig, f24.revenue AS rev_2024, f25.revenue AS rev_2025, CASE WHEN f24.revenue > 0 AND f25.revenue IS NOT NULL THEN LEAST(GREATEST(f25.revenue / f24.revenue - 1, -0.5), 0.5) + 0.5 ELSE 0 END AS dyn, CASE WHEN c.kved_ambig = 0 AND c.employees IS NOT NULL AND c.region IS NOT NULL AND c.region <> '' THEN 1 ELSE 0 END AS compl FROM companies c LEFT JOIN fin_history f24 ON f24.code = c.code AND f24.year = 2024 LEFT JOIN fin_history f25 ON f25.code = c.code AND f25.year = 2025 WHERE c.status = 'зареєстровано' AND c.has_financials = 1 AND c.source IS NULL AND c.kved_2010 LIKE '31%' AND c.employees BETWEEN 50 AND 249) t ORDER BY score DESC, COALESCE(t.rev_2025, t.revenue) DESC LIMIT 12
```
