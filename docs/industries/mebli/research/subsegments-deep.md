## 2. (в) М'які меблі

**Ланцюг.** Модель (каркас, наповнення, оббивка) + вибір тканини **за категорією** → замовлення (салон, дилер) → перевірка наявності тканини в рулонах → **розкладка лекал на тканині** й розкрій (ручний чи CAD/CAM) → пошиття чохлів → каркас (брус, фанера, ДСП) і ППУ → оббивка й збирання → контроль, пакування → доставка.

| Документ | Зміст |
|---|---|
| Специфікація моделі | каркас, ППУ (марка, щільність), механізм, тканина в п.м. / м² за категорією |
| Прайс за категоріями тканин | ціна моделі × категорія (CPQ-клас, M) |
| Лекала й карта розкладки | деталі чохла на ширині рулону; напрям ворсу, малюнок |
| Облік рулонів | артикул, партія фарбування, залишок у метрах |
| Наряд оббивника / швачки | операції, відрядна |
| Замовлення постачальнику тканини | під замовлення клієнта, якщо тканини немає |

## 3. (г) Меблі з масиву і столярка

**Ланцюг.** Закупівля пиломатеріалу (порода, сорт, товщина, м³) з документами походження → **сушіння** (камера, вологість) → розкрій пиломатеріалу (вихід придатного, відходи) → склеювання щитів, гнуття → фрезерування, шліфування → **оздоблення** (лак, масло, фарба; час висихання) → збирання → пакування → експорт (ЄС, США) з декларацією походження (EUDR).

| Документ | Зміст |
|---|---|
| Приймання пиломатеріалу | порода, сорт, розміри, м³, постачальник, документ походження |
| Журнал сушіння | камера, партія, вологість на вході й виході, дати |
| Розкрійна карта пиломатеріалу / вихід | м³ → деталі, % виходу, відходи |
| Технологічна карта з оздобленням | операції, матеріали оздоблення, час висихання |
| Специфікація виробу | деталі в м³ і м², фурнітура |
| Декларація due diligence (EUDR) | геолокація лісоділянки, партія → виріб |

2. **Операційна частина (сушіння, м³ і сорти, вихід) не досліджена.** Українських джерел про ці болі голосом виробника немає, вакансій сушильника — нуль. **Рішення про окремий пакет (г) неможливе.** Оцінку гостроти операційних болів R5 (4) знято; для EUDR вона лишається 4 (регулятор).
3. **Системи для столярки** (BORM, forma office, CAD+T) — німецькомовний ринок, CAD → ERP. Українських систем для (г) не знайдено.
